This section contains the complete internship worklog for the **First Cloud AI Journey (FCAJ Workforce Bootcamp)** program across **12 weeks** (from **14/09/2026 to 14/12/2026**).

Aligned with the **Information Assurance** major and AWS Cloud engineering track, this worklog documents the progression from AWS Cloud fundamentals and multi-tier network security to private connectivity via VPC Endpoints, Serverless API and authentication architecture, secrets and encryption management, edge security, cloud security monitoring (SecOps), and final system verification under the AWS Well-Architected Framework.

Weekly worklog directory:

**Week 1:** [Onboarding FCAJ Workforce, Cloud Foundation & AWS IAM Security](1.1-week1/) *(14/09/2026 – 18/09/2026)*

**Week 2:** [AWS Networking Architecture (Amazon VPC, Subnets, Routing, NAT Gateway & Security Groups)](1.2-week2/) *(21/09/2026 – 25/09/2026)*

**Week 3:** [Compute Services & Secure Server Management (Amazon EC2, EBS, AMI & SSM Session Manager)](1.3-week3/) *(28/09/2026 – 02/10/2026)*

**Week 4:** [Managed Databases & Cloud Storage (Amazon RDS Multi-AZ, Amazon S3 & Pre-signed URLs)](1.4-week4/) *(05/10/2026 – 09/10/2026)*

**Week 5:** [Solution Architecture Design, AWS Well-Architected Framework & Cost Estimation](1.5-week5/) *(12/10/2026 – 16/10/2026)*

**Week 6:** [Private Connectivity with S3 Gateway Endpoint, Interface Endpoint & Route 53 Private DNS](1.6-week6/) *(19/10/2026 – 23/10/2026)*

**Week 7:** [Serverless Backend & Authentication Architecture (AWS Lambda, API Gateway & Amazon Cognito)](1.7-week7/) *(26/10/2026 – 30/10/2026)*

**Week 8:** [Encryption Key Management, System Secrets & Data Protection (AWS KMS, Secrets Manager & Parameter Store)](1.8-week8/) *(02/11/2026 – 06/11/2026)*

**Week 9:** [Web Application Layer Security & Content Delivery (Amazon CloudFront, AWS WAF & ACM)](1.9-week9/) *(09/11/2026 – 13/11/2026)*

**Week 10:** [System Observability, Audit Logging & Automated Alerting (CloudWatch, CloudTrail & Amazon SNS)](1.10-week10/) *(16/11/2026 – 20/11/2026)*

**Week 11:** [Threat Detection, Security Posture Assessment & Infrastructure as Code (GuardDuty, Security Hub & CloudFormation)](1.11-week11/) *(23/11/2026 – 27/11/2026)*

**Week 12:** [End-to-End Testing, Cost Optimization & Finalizing Workshop and Internship Report](1.12-week12/) *(30/11/2026 – 04/12/2026)*
